# Impossible Mission II features

The manual describes several platforms. Controls below use its C64 instructions. Open rows are questions for the tape build.

- Epyx, *Impossible Mission II Instruction Manual*, part 1240A-60 Rev. A, 1988. Read 20 November 2026. [Manual scan](https://quartdepomme.fr/quartdepomme/PDF___Games_manuals_files/Impossible%20Mission%20II%20Instruction%20manual.pdf).

| Feature | Status | Evidence |
|---|---|---|
| Start in an elevator in one of eight outer towers with eight hours on the clock. | live | The opening elevator and ticking clock are visible in reference/elevator.png. The choice of starting tower is open. |
| Port 2 joystick changes floors in elevators, moves along corridors and enters rooms. | traced | The port-2 left read is confirmed at $336C. Floor and corridor transitions are open. |
| In rooms the stick moves left and right. Fire jumps; up operates lifts and searches or interacts with the object in front of the agent. | open | Manual pp. 4–5. |
| Searches take time and can be interrupted. Objects can yield a passcode digit or a security command. | open | Manual p. 5. |
| Security terminals spend collected commands to reset lifts, deactivate robots temporarily, restore lights, or arm an explosive or mine. | open | Manual pp. 5–6. |
| Safes yield musical sequences. The pocket computer records them and lets the player rewind, play, fast-forward and replace duplicates. | open | Manual pp. 6–7. |
| The pocket computer shows visited rooms and the player's position. Its code-entry mode checks three digits for access to the neighboring towers. | open | Manual pp. 6–7. |
| Neighboring towers connect above and below ground. Collected music opens express elevator access to the central control room. | open | Manual pp. 7–9. |
| The final room has three terminals. The correct one stops the launch. The others kill the agent. | open | Manual p. 8. |
| The score accounts for rooms, towers, objects, digits and completing the mission. A scoreboard appears when time expires, the mission ends or the agent dies too many times in the control room. | open | Manual p. 8. |
| RESTORE starts a new mission, RUN/STOP pauses, and the Commodore key sacrifices the agent when trapped. | open | Manual p. 8. |
| Commodore+S saves from an elevator or hallway. | open | Manual p. 8. Availability on the tape edition is open. |
| The manual describes sentrybots, minebots, pestbots, squatbots, bashbots and suicidebots. | open | Manual appendix B. |
