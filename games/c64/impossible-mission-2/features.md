# Impossible Mission II features

The manual describes several platforms. Controls below use its C64 instructions. Open rows are questions for the tape build.

- Epyx, *Impossible Mission II Instruction Manual*, part 1240A-60 Rev. A, 1988. Read 20 November 2026. [Manual scan](https://quartdepomme.fr/quartdepomme/PDF___Games_manuals_files/Impossible%20Mission%20II%20Instruction%20manual.pdf).

| Feature | Status | Evidence |
|---|---|---|
| Start in an elevator in one of eight outer towers with eight hours on the clock. | live | The opening elevator and clock are visible in reference/elevator.png. With the tape mode flag at one, the startup path wrote tower index zero at $0A1E. |
| Port 2 joystick changes floors in elevators, moves along corridors and enters rooms. | traced | A read watch confirmed port 2 left at $336C. The elevator floor update admits a step below the bound at $18E2, and $3E63 checks both corridor exit thresholds. |
| In rooms the stick moves left and right. Fire jumps; up operates lifts and searches or interacts with the object in front of the agent. | traced | The room input loop uses the fire bit at $3CCF and checks an interaction tile at $3CFC. The sampled tile and coordinate paths are at $3F4A and $3A77. The full input conditions for jumps, lift steps and searches remain open. |
| Searches take time and can be interrupted. Objects can yield a passcode digit or a security command. | live | In a controlled search update, $6606 decremented the countdown when $A396 was set and bit zero of $4C was one. $665A–$66AD handles the result classes. The mapping of all reward codes to the manual names remains open. |
| Security terminals spend collected commands to reset lifts, deactivate robots temporarily, restore lights, or arm an explosive or mine. | traced | The command handler spends a charge at $69E2 and branches on selections one through six. A watch confirmed selection six also clears $8DC5 at $6A2C. Some command names and their room effects remain open. |
| Safes yield musical sequences. The pocket computer records them and lets the player rewind, play, fast-forward and replace duplicates. | traced | Reward code seven calls the inventory append at $6698. The console has three 25-byte melody slots selected at $12C8. The mapping of the individual transport buttons remains open. |
| The pocket computer shows visited rooms and the player's position. Its code-entry mode checks three digits for access to the neighboring towers. | traced | The room glyph paths at $2670 and $2751 mask the low nibble of the packed room byte. The four-cell cursor is drawn at $27BD. The three-digit access check remains open. |
| Neighboring towers connect above and below ground. Collected music opens express elevator access to the central control room. | open | The tower advance at $1D84 increments the index modulo eight. The controlled $2204 path requests record 128. Prerequisites for the upper and lower connections and express access remain open. |
| The final room has three terminals. The correct one stops the launch. The others kill the agent. | live | A controlled entry at $692F reached $6943 for descriptor value three and $6949 for value two at coordinate $0F. At $10 it reached the standard console branch. The legal-input route and the placement of the three terminals remain open. |
| The score accounts for rooms, towers, objects, digits and completing the mission. A scoreboard appears when time expires, the mission ends or the agent dies too many times in the control room. | traced | The scores part uses weights 1, 2, 3 and 20 for pins, objects, music and towers. An execution stop confirmed expiry runs the overlay loader via $2953. The other trigger conditions and the complete scoring formula remain open. |
| RESTORE starts a new mission, RUN/STOP pauses, and the Commodore key sacrifices the agent when trapped. | open | The resident NMI path at $3012 changes control flow according to $67 and $A1D1. The room input loop at $3B09 dissolves the sprite if CIA1 port B bit five is clear. Mapping these paths to all three manual keys remains open. |
| Commodore+S saves from an elevator or hallway. | open | The saved-state branch at $0AD7 is bypassed with the tape mode flag at one. $0A8A scans the Y/N resume prompt in the alternate path. The keyboard combination and a save-to-media path remain open. |
| The manual describes sentrybots, minebots, pestbots, squatbots, bashbots and suicidebots. | open | The actor initializer tests the type field at $7BB6 and the script dispatch at $7311 was traced for commands $01, $05 and $1D. The correspondence between type numbers and the six manual names remains open. |
