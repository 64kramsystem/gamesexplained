# Features

Source consulted on 19 November 2026: [The Trap Door – C64-Wiki](https://www.c64-wiki.com/wiki/The_Trap_Door).

| Status | Feature |
|---|---|
| open | Learner and Super Berk modes differ in tasks, ghosts, scoring and the final reward. |
| confirmed | Default keys Q/A/Z/X and joystick port 2 enter the direction dispatcher. The mode and controls screens show the keyboard settings and a redefine option. Room transitions remain open. |
| traced | C and T dispatch to separate drop and tip handlers. The resulting object changes and the rules for pushing, carrying and levers remain open. |
| open | The trap door releases worms and other creatures. Drutt eats worms, Boni offers hints, and ghosts can be fed. |
| open | The Thing calls for dishes, and the anger meter gives the remaining time. The lift delivers food for judging. Score depends on time and preparation. |
| open | The documented dishes are worms, crushed eyeballs, boiled slimies and fried eggs. Each involves a distinct creature or preparation. |
| open | The final cleanup leads to a safe in Super Berk mode. The drop height of the weight determines the outcome. |
| traced | The controls screen installs the title music IRQ hook at $186E. The sequence and its $57 repeat event were traced. C64-Wiki credits David Dunn. |
