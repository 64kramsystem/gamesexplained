# Analysis history

The native Beastie Boys disk load reached the crack intro after two unpackers. A direct PRG injection did not reproduce the native chain, so the handover and gameplay captures use disk autostart. The Fantastic Crew and Silents downloads in the ignored work folder are alternate releases kept apart from the analysis.

An execution checkpoint at $801A captured the game before initialization. The difference from the pre-unpack credit screen established the final payload's lower bound. The final unpacker's output pointer and branching established the upper bound. The listing uses that handover and the runtime code map uses brief input probes from the opening area.

The first disassembly walk left several callable blocks untyped because the game patches JSR operands. The actor, movement mode, and inventory dispatch tables supplied the missing seeds. A misaligned first pass on the actor-spawn pointer table was corrected against the two indexed loads at $9D83 and $9D88.

All emulator snapshots, reference renders used during analysis, annotation source files and trace scripts are in ignored work/. The source listing and symbol export are the tracked records.
