# Kendo Warrior analysis history

The first disk found under the title was a 1992 music rip. The packer ran and produced a SID playback menu instead of the game. The analysis uses the 2004 Hokuto Force game release with all trainer options declined. A DCS release and the publisher's tape provide independent comparison points at `$0880`, with only the Hokuto Force disk used for the listing.

Disk autostart spent a long time at the drive-load screen. The reproducible route injects the extracted file and enters it from BASIC with its SYS command. Setting the PC directly did not provide that BASIC call context. Joystick and matrix input worked with the installed headless emulator. The emulator check recorded its host-key failure and checkpoint-list exception.

The scope ends at the analysis handoff. The ignored directory holds the edit log, annotation batches, test script and captured evidence.
