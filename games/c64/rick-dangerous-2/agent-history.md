# Analysis session

The Alex Software disk booted on headless VICE MCP v3.14.0 with dummy audio. A single seeded Regenerator2000 request completed after a large execute-map batch timed out. Further starts were seeded individually or from decoded jump tables. Level maps were exported from local Regenerator2000 projects.

A loader-return checkpoint at $7CF4 yielded each overlay. The resident hand-over at $0400 was recovered by stopping at $8A00, then stopping again after the relocation copy. The full boot and later gameplay execute maps are kept separately in ignored work/ because the first mixes loaded images at the same addresses.

The coverage resume used the saved engine snapshots and compared the re-export with the baseline ledger byte by byte. It recovered the draft export's missing $4911–$492F by tracing the common special-object motion stream. The music command dispatch and high-score opcode changes were traced with the kit's CPU simulator. The Headquarters right-edge read trace and a search for matching pixel sequences left its 293-byte span unresolved. The ignored `work/` scripts retain the exact test setup.

The later coverage resume reconstructed an offline project from the 40,632-byte engine export before adding effect state, column renderer and loader annotations. A headless VICE execution checkpoint confirmed 254 visits to the startup zero-page store. A CPU trace found no earlier reads of those RAM bytes, and the ledger now excludes the runtime page. All six listings were rebuilt. The Headquarters stream and earlier read traces left the counted gap unresolved.

The next resume brought the resident engine to 40,988 of 40,988 explained bytes. It traced the per-channel music operand patches, shared sprite animation phases and individual score-panel stores. In Headquarters, a VICE watch confirmed the normal right-edge fetch stops at $8EB7. A separate trace followed the actual incoming room transfer and found that its starting camera can run past the scrolling limit. The transfer's initial redraw read 24 further metatile bytes through $8ECF. Depacker provenance ruled out stale RAM as their source and as the source of the following 269-byte span. The remaining span stays in the ledger.

The final coverage pass decoded the Headquarters five-byte records as a planar strip and kept all of their bytes in the denominator. The verification pass reran the depacker instruction trace, the VICE read watches for the room redraw and the startup clear checkpoint. A separate checker sampled the six listings. The sample verdicts, export generator and final projects are in ignored `work/`. The directed tests for this pass establish code behavior from prepared states. They do not claim a player route, so step 65 had no recording to produce.
