# Analysis session

The Alex Software disk booted on headless VICE MCP v3.14.0 with dummy audio. A single seeded Regenerator2000 request completed after a large execute-map batch timed out. Further starts were seeded individually or from decoded jump tables. Level maps were exported from local Regenerator2000 projects.

A loader-return checkpoint at $7CF4 yielded each overlay. The resident hand-over at $0400 was recovered by stopping at $8A00, then stopping again after the relocation copy. The full boot and later gameplay execute maps are kept separately in ignored work/ because the first mixes loaded images at the same addresses.
