# Current findings

- Gameplay takes IRQs through the RAM hardware vector at $FFFE, set to $0DAE with processor port $35. The handler saves A, X and Y at $0DA8–$0DAA and uses $57 to select its branch. Both the handler and the main loop were seen in the running image.
- The main loop at $0549 waits until $54 reaches two. At $53D7 the engine also uses the counter to time a delay, counting down X once per two ticks. At $53E9 the interruptible delay reads bit 4 of CIA1 port A and returns early while joystick 2 fire is held.
- During the disk load the machine uses $36. The CPU instruction trace shows $EE5A–$EE63 sampling $DD00 as part of the KERNAL serial transfer. The $FFD5 entry checkpoint was armed before selection and registered no hits during the full Hyde Park load. $7CC0 builds the filename and calls the streamed depacker at $88A7.
- The stored menu text is directly readable in PETSCII from $09D1, $09E9, $0A0B, $0A2C and $0A48 in `work/title.vsf`. The menu shows five destinations. The fifth is drawn blue in a fresh game.
- Initial gameplay in Hyde Park and the Ice Caverns uses the same wait loop at $0549, while large regions of memory change between the two images. This establishes a resident engine and distinct load states. The exact overlay spans are $8A00–$BFFF and $D800–$EFFF. The instruction trace reproduced every byte in all five loader-return snapshots.
- At an exact execution stop on $0DE9, $54 held zero. A single instruction step executed `INC $54`, left the PC at $0DEB, and changed the byte to one. The main loop's compare at $054B waits for two.
- The selected level in A reaches the loader entry at $7D4B. On the campaign continuation path, $14AD stores the unlock flag at $0A66 and the code loads the next level. The select screen changes the fifth item's colour and extends the cursor limit when this flag is set.
- The room directory starts at $A400. Eight-byte records supply a metatile map address, a right-scroll limit and two list offsets. The engine reads four-byte exit records and variable-length object records. A zero type ends either list. The object header's fourth byte gives a descriptor count in its low two bits.
- The renderer expands one vertical column at a time. $5056 reads eight metatile IDs, and $507C reads each corresponding group of four character bytes. $520E reads the colour for the resulting character from $A100. The tile-contact sampler uses a separate table at $A000.
- The VIC's bank begins at $C000. The raster handler selects $F000 as character RAM with the $0C setting in $D018 and the level's character data at $E800 with $0A. The level input remains in RAM under I/O when the VIC fetches it.
- An execute checkpoint at $3437 during a joystick-2 right press stopped with both the CIA1 port read and A at $77. Before the store, $6F was $7F. One instruction step wrote $77 to $6F and advanced to $3439. The player routine therefore receives the active-low port value, including the right bit directly.
- The level setup at $0BDB patches the object template address from the five little-endian words at $86B2. From Hyde Park through Headquarters the table bases are $AEE0, $B3C9, $B4E5, $B083 and $B434. Initialised gameplay snapshots show those same operands.
- The story interpreter dispatches at $454F. A zero opcode ends the stream. Opcode five chooses a picture or blanks the display, six draws a line through a $FF terminator, and nine waits while updating sprites. Level-specific picture and script pointers come from $86BC and are installed at $0BF4.
- On a display-mode change, $0C8E swaps 112 glyphs between $4BDF and $E800. This initially moves the common title glyphs to $E800. Level transitions can then reuse the same VIC character address while retaining the other set.
- In Hyde Park, fire plus up reached $2807 with A equal to five and the shot counter at six. Stepping that store changed $6B to five. Fire plus down reached $275A and its store changed the explosive counter at $6A from six to five. The code uses separate active slots and redraw flags for these ammunition types.
- Headquarters includes a retained scene fragment at $AAD5. During its entry scene an execute checkpoint stopped at $4732 with the script pointer at $A9A2. The command there was `0D D5 AA`. Eight instructions advanced the pointer to $A9A5 and left the PC in the command dispatcher, leaving the referenced fragment unexecuted.
