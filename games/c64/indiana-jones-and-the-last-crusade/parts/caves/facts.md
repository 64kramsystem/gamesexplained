# Caves

The renderer reads 256-byte rows from the map at `$3600` and displays the loaded glyphs from `$2800`. The filename stop at `$B85E` selected `INDIANA1  (EBES)`. The part listing uses the snapshot taken at `$B861`, when the loaded cells are present before stage initialization changes them.

See [orientation.md](../../orientation.md) for the measured write ranges and [the stage screenshot](../../reference/caves.png).
