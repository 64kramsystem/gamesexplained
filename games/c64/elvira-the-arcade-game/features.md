# Features

| Status | Feature and evidence |
|---|---|
| live | The boot offers English, German and Italian. The English route reaches the globe selector. |
| live | Control port 2 moves the pointer. The left globe selects Fire and the right globe selects Ice. The centre hotspot opens the high scores. |
| live | Each of the two tested globes offers Easy, Medium and Hard on keys 1, 2 and 3. Fire advances the world picture and Space starts play from the quest prompt. |
| live | Fire starts next to a sign on rocky ground. Ice starts on snow with a snowfall effect. Both show a score, lives, a centre panel and an energy bar. |
| live | Holding Down enters the crouch path at $2392 in Fire. |
| traced | Jump and terrain probes, object contact, projectile collision and viewport edge updates are described in the quest listings and facts. |
| traced | The energy updater caps the meter at 40. Pickup ID $11 queues four units. The spell code reads Return for activation and Space for selection. Two spell types temporarily replace the weapon byte. |
| traced | The trader screen offers four spell exchange choices. Controlled steps verified the HUD pointers and the colour restoration path. |
| traced | The exit dispatcher reaches Castle and the ending with the documented selectors in debugger-driven transitions. Controlled traces verified the Castle contact and spell exit requests. |
| traced | The score adder carries across the decimal digits. The death path decrements lives, and a spell can add one life up to nine. The music players decode track and pattern tables in the listings. |
| open | Fall-damage conditions, projectile capacity and the full set of pickups, upgrades and teleporters described in the manual. |
| open | The ordinary play conditions for reaching the Castle and winning exits, and the king's role during play. |
| open | The gameplay effects of each difficulty, the complete retry sequence, high-score entry and the conditions that select each music track. |
